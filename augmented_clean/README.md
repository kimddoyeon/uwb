## 생성 기준

- 원본 로그 전체에서 유효하게 측정된 쌍의 연결 관계를 합쳐 판단했습니다.
- A와 B는 제거하지 않았습니다. C~F에서 1개 또는 2개를 제거한 뒤 B에서 연결되는 성분만 유효 노드로 셌습니다. A가 끊기거나 유효 노드가 4개 미만인 조합, 동일한 유효 노드 집합을 만드는 중복 조합은 제외했습니다.
- 원본 로그는 바이트 단위로 복사했습니다. 증강 로그는 유지된 쌍의 원본 측정값을 보존하고, 제거 또는 연결 단절된 노드가 포함된 쌍의 거리·RSSI·FP를 `nan`으로, 관련 비트마스크를 해제했습니다. 이 쌍은 표에서 `INACTIVE`로 표시했습니다.
- `SOURCE_GATEWAY`는 원본 측정의 실제 경로 기록입니다. `SIM_GATEWAY`는 새 노드 조합의 가상 배정이며 실제 재측정 결과가 아닙니다. 후보는 B와 직접 연결된 노드(A 포함) 중 다른 유효 노드와 가장 많이 연결된 노드입니다. 동률은 사진 배치의 가운데에 가까운 노드로 정했습니다. 2공 1층의 이동 배치는 게이트웨이를 빈칸으로 두었습니다.
- PDF의 초록 원은 유지, 빨간 X는 물리적 제거, 주황 사선은 제거 후 연결 단절, 금색 원은 가상 게이트웨이입니다. 이동 배치의 표시는 사진에 적힌 이동 경로의 노드 라벨을 가리키며 고정 위치를 뜻하지 않습니다.

## 빈 거리·오차 칸

엑셀의 구조 항목은 기존 현장 기록의 LOS/NLOS·벽·문·코너 값을 원본 배치에서 확인해 유지된 쌍에 옮겼습니다. 물리적 제거로 전원을 끈 노드와 전원은 켜져 있지만 연결이 끊긴 노드를 구분했습니다. 2공 1층 이동 배치처럼 한 배치 안에서 상태가 바뀌는 쌍의 환경값은 고정하지 않았습니다. 기존 기록에는 문 상태 `none`과 `open`만 있고 `close`는 확인되지 않았습니다.

2공 1층 PDF 1쪽에 A–B 실거리 4.7m가 직접 표시되어 있어, 고정 노드 A·B의 모든 로그에 대해 AB 평균 절대오차를 계산했습니다. 다른 쌍의 `실제 거리 (m)`와 `평균 절대오차 (m)`는 부분 치수의 끝점이나 이동 중 위치가 확정되지 않아 비워두었습니다. 빈칸은 0이 아닙니다. 실거리가 확인되면 각 쌍의 평균 절대오차는 유효한 원본 측정값마다 `|측정거리 - 실제거리|`를 계산한 뒤 평균해야 합니다. `측정 평균`이나 `측정 중앙값`과 실거리의 차이만으로 대체하지 마세요.
