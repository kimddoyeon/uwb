## 2공 4층 중복 점검

PDF 앞쪽의 4노드·5노드 실측 로그 42개를 추가했습니다. 6노드 원본 4개를 포함해 실측 원본은 46개입니다. 6노드에서 만든 파생본 27개를 앞쪽 실측 배치의 노드 위치와 로그 전체 연결 관계로 대조하여 아래 3개를 제외했습니다. 노드의 문자 이름이 달라도 실제 위치와 연결 구조가 일치하면 중복으로 판정했습니다.

## 환경과 오차

- 엑셀은 물리적으로 전원을 끈 노드(`꺼짐`), 전원은 켜졌지만 연결이 끊긴 노드, 실측 당시 배치되지 않은 노드(`미배치`)를 구분합니다.
- LOS/NLOS, 벽, 문, 코너는 기존 현장 엑셀에 기록된 값을 각 원본 배치에서 가져와 유지된 쌍에 적용했습니다. `closed`와 오타 `opne`는 요청하신 표기 `close`·`open`으로 정규화했습니다. 기존 기록이 없는 경우, PDF에서 문 앞 노드와 X 표시를 직접 확인할 수 있는 일부 쌍만 입력했습니다. 도면의 다른 문에 X가 없다는 사실만으로 일괄 `open` 처리하지 않았습니다.
- 2공 1층의 이동 배치는 게이트웨이를 로그에서 빈칸으로 두고, 위치에 따라 달라지는 쌍의 환경·실거리를 고정하지 않았습니다.
- 2공 1층 PDF 1쪽에 직접 표시된 A–B=4.7m를 모든 해당 로그에 적용했습니다. 사용자가 도면에서 확인한 `150150`의 B–C 약 7.7m도 해당 원본과 유효한 파생 로그에 반영했습니다. 유효한 원본 측정값마다 `|측정거리−실거리|`를 계산해 평균 절대오차를 적었습니다.
- 5강 1층 `17:30:42`의 A–B 실거리에는 사용자가 계산한 9m를 적었습니다. 이 원본 로그에는 A–B 유효 측정이 한 건도 없어 해당 로그와 파생 로그의 평균 오차는 빈칸입니다.
- 다른 쌍은 PDF의 부분 치수 끝점·이동 중 위치·기존 엑셀의 상충 값이 확정되지 않아 실거리와 오차를 빈칸으로 뒀습니다. 빈칸은 0m나 오차 0을 뜻하지 않습니다.

증강 로그는 원본의 유효 쌍 측정값과 시간 순서를 보존하고 제외 쌍의 값·마스크만 비활성화했습니다. `SOURCE_GATEWAY`는 원본의 실제 경로 기록이고 `SIM_GATEWAY`는 새 구성의 가상 배정입니다.
같은 원본에서 만든 여러 조합에 동일한 쌍이 남아 있으면 그 쌍의 측정값과 평균 오차도 동일하게 나옵니다. 이는 측정값을 임의로 생성하거나 변화시키지 않았기 때문입니다.
